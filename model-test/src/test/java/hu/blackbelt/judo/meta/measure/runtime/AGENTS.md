# `model-test/src/test/java/hu/blackbelt/judo/meta/measure/runtime` — dual-engine (EVL vs Java) validation tests over the generated `MeasureModel`

| File | Purpose |
|---|---|
| `AbstractMeasureValidationTest.java` | Shared fixture routing one test body to two validation engines. Exposes `measureModelSupport`, `measureModel`, `validatorType` (defaults `EVL`), `initModel()` / `initModel(String)`, and three `runValidation(...)` overloads. `@BeforeEach setUp` nulls both model fields, so a subclass MUST call `initModel()` after assigning `validatorType` or dereference null. EVL path counts `EvlScriptExecutionException.getUnexpectedErrors()` by constraint name, splitting Epsilon's `Name\|Message` at the first `\|`; a null expected collection means "do not check", an empty one means "must be empty". Default model URI `urn:Measure.model`, model name `test`. |
| `MeasureExecutionContextTest.java` | Smoke test that `measureModelResourceSupportBuilder().uri(...)` constructs over `urn:measure.judo-meta-measure` without throwing. Single `@Test testMeasureReflectiveCreated`; body stops at the builder and asserts nothing — it guards construction only, not model content. |
| `MeasureUtilsTest.java` | Pins the three-state contract of `MeasureUtils.validateUniqueXmiids()`. `testValidateUniqueXmiids` asserts `IllegalStateException("Model's ResourceSet is unknown (null)")` before `setResourceSet`, then `"There are non-unique xmiid-s\nXmiid <id> must be unique\n"` after `setId` collides two `BaseMeasure`, then `assertDoesNotThrow` once ids differ. Messages are asserted verbatim — changing wording breaks this test. |
| `MeasureValidationPerformanceTest.java` | Benchmarks EVL against sequential and parallel `MeasureValidator.validateMeasure` on a generated model of 100 `BaseMeasure` + 100 `DerivedMeasure`, 1–5 `Unit` each, `Random(42)` for reproducibility. Single `@Test testPerformanceComparison`; expects zero errors/warnings from every engine, so a new constraint firing on the generated shape fails it. Timings go to the log only — no assertion on speed. |
| `MeasureValidationTest.java` | Nine `@ParameterizedTest` + `@EnumSource(ValidatorType.class)` cases over `AbstractMeasureValidationTest`, covering `MEASURE_SYMBOL_IS_UNIQUE`, `UNIT_SYMBOL_IS_UNIQUE_IN_MEASURE`, `UNIT_NAME_IS_UNIQUE`, `UNIT_SYMBOL_IS_UNIQUE`, base-unit presence, and a valid `DerivedMeasure`. Encodes the known engine divergence: EVL deduplicates warnings by message (1 entry) while Java reports per `Unit` (2), branched on `validatorType`. Every case sets `this.validatorType = type` then `initModel()` first. |
| `ValidatorType.java` | Two-constant enum selecting the validation engine per parameterized run: `EVL` (Epsilon script) and `JAVA` (Zeta native). Drives `@EnumSource(ValidatorType.class)`; `AbstractMeasureValidationTest.runValidation` throws `IllegalStateException` on any unhandled constant, so a new constant needs a matching dispatch branch. |
