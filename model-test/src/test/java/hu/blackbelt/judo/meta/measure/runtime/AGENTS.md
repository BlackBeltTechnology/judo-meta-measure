# `model-test/src/test/java/hu/blackbelt/judo/meta/measure/runtime` — dual-engine (EVL vs Java) validation tests over the generated `MeasureModel`

| File | Purpose |
|---|---|
| `AbstractMeasureValidationTest.java` | Shared fixture routing one test body to both validation engines; exports `initModel()`, `runValidation(...)`, `validatorType`. → see `AbstractMeasureValidationTest.AGENTS.md` |
| `MeasureExecutionContextTest.java` | Smoke test that `measureModelResourceSupportBuilder().uri(...)` constructs over `urn:measure.judo-meta-measure` without throwing. Single `@Test testMeasureReflectiveCreated`; body stops at the builder and asserts nothing — guards construction only, not model content. |
| `MeasureUtilsTest.java` | Pins the three-state contract of `MeasureUtils.validateUniqueXmiids()`. Asserts `IllegalStateException("Model's ResourceSet is unknown (null)")` before `setResourceSet`, then `"There are non-unique xmiid-s\nXmiid <id> must be unique\n"` once `setId` collides two `BaseMeasure`, then `assertDoesNotThrow`. Messages asserted verbatim — rewording them breaks this test. |
| `MeasureValidationPerformanceTest.java` | Benchmarks EVL against sequential and parallel `MeasureValidator.validateMeasure` over a generated model of 100 `BaseMeasure` + 100 `DerivedMeasure`, 1–5 `Unit` each, `Random(42)` for reproducibility. Expects zero errors and warnings from every engine, so a new constraint firing on the generated shape fails it. Timings are logged, never asserted. |
| `MeasureValidationTest.java` | Nine `@ParameterizedTest` + `@EnumSource(ValidatorType.class)` cases over `AbstractMeasureValidationTest`, covering `MEASURE_SYMBOL_IS_UNIQUE`, `UNIT_SYMBOL_IS_UNIQUE_IN_MEASURE`, `UNIT_NAME_IS_UNIQUE`, `UNIT_SYMBOL_IS_UNIQUE`, missing base unit, valid `DerivedMeasure`. Encodes engine divergence: EVL deduplicates warnings by message (1), Java reports per `Unit` (2). |
| `ValidatorType.java` | Two-constant enum selecting the validation engine per parameterized run: `EVL` (Epsilon script) and `JAVA` (Zeta native). Drives `@EnumSource(ValidatorType.class)`; `AbstractMeasureValidationTest.runValidation` throws `IllegalStateException` on an unhandled constant, so a new constant needs a matching dispatch branch. |
